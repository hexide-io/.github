# HexIDE

**An open, cross-platform IDE for Visual Basic 6.**

A recreation of the Visual Basic 6 workbench — forms, toolbox, properties, project explorer —
running natively on Windows, macOS and Linux. It opens and runs real VB6 projects, and it is
straight with you about what it cannot yet hand back.

> [!WARNING]
> **Alpha — saving is not yet round-trip faithful.** A save can delete binary companion files and
> rewrite class settings you never touched. Work on a copy, not on a project you care about.
> [Exactly what goes wrong →](https://hexide.io/scope.html#saving)
